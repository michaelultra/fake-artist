    How a round works
    1. The host clicks Next Game. Everyone sees the same category. Everyone sees the same word, except one player who sees FAKE.
    2. On Zoom, take turns adding one line each to a shared drawing of the word. The fake bluffs.
    3. Vote on who the fake is. The host clicks Reveal to show the answer and the word.
    4. Next Game deals a new word and a new fake. Last round's fake is never picked twice in a row.
